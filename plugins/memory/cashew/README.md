# Cashew Memory Provider Plugin

Persistent thought-graph memory for Hermes Agent, backed by [cashew-brain](https://github.com/rajkripal/cashew).

## Quick Start

```bash
hermes plugins install cashew
CASHEW_PIN='cashew-brain @ https://github.com/rajkripal/cashew/archive/dd57ef029cf9a6dce0b8145d335a55202dd1bac4.tar.gz#sha256=38d2cb085fc8970a285991fca5df6b44309324b80947bb816f738a9acaaf72ab'
uv pip install --python ~/.hermes/hermes-agent/venv/bin/python3 \
  --reinstall "$CASHEW_PIN" sqlite-vec
~/.hermes/hermes-agent/venv/bin/python3 \
  ~/.hermes/plugins/cashew/scripts/verify-cashew-baseline.py
hermes memory setup    # configure provider
hermes gateway restart
```

The manual dependency step is currently required because Hermes rejects direct
URL dependencies from plugin manifests. The selected upstream source and the
older PyPI release both report version `1.2.1`, so keep the provenance check.
Reapply and verify the pin after `hermes plugins update cashew`, `hermes update`,
or a Hermes virtual-environment rebuild.

## Configuration

Configured via `~/.hermes/cashew.json` (auto-generated by `hermes memory setup`).

### Required

| Key | Default | Description |
|-----|---------|-------------|
| `llm_aux_role` | `memory` | Selects the explicitly configured `auxiliary.memory` role for LLM-powered extraction and thinking; absent or null mappings remain heuristic-only. |

### Performance

| Key | Default | Description |
|-----|---------|-------------|
| `sync_queue_timeout` | `30.0` | Seconds to wait for the sync queue to drain on shutdown |
| `think_interval` | `10` | How many sync turns between think cycles (0 = disable) |

### Features

| Key | Default | Description |
|-----|---------|-------------|
| `sleep_cycles` | `True` | Enable graph consolidation on the persistent Hermes cron schedule. |
| `think_cycles` | `True` | Enable periodic insight generation |

### Storage

| Key | Default | Description |
|-----|---------|-------------|
| `cashew_db_path` | `cashew/brain.db` | Relative to `$HERMES_HOME` |
| `embedding_model` | `thenlper/gte-large` | Sentence-transformers model for embeddings (1024-dim) |
| `embedding_device` | `cpu` | Safe default; use `auto`, `mps`, or `cuda` only after validating the backend |

The `cpu` default prevents SentenceTransformer from automatically selecting an
accelerator. Model loading and encoding run in one provider-owned child process;
an exit cannot terminate Hermes, and interactive callers stop waiting after a
bounded interval when it hangs. Explicit non-CPU startup failures retry once on
CPU, still inside the child.

This boundary covers SentenceTransformer only. SQLite, sqlite-vec, adapter
NumPy operations, graph algorithms, and auxiliary LLM calls remain in the
Hermes process. Real-model latency and memory use vary by model and hardware.

### Retrieval

| Key | Default | Description |
|-----|---------|-------------|
| `recall_k` | `5` | Context fragments returned per query |

Starting with v0.11.0, the deprecated retrieval, classification, clustering,
and garbage-collection tuning keys are removed because cashew-brain 1.x has no
supported API to consume them. They never changed provider behavior. Existing
files continue to load; removed keys are ignored and pruned the next time
`hermes memory setup` saves the provider configuration. Remove matching
`CASHEW_*` environment variables as part of the upgrade.

## Tools

The provider exposes two tools to the LLM:

### `cashew_query`

Recall context from the thought graph. Accepts `query` (required), `max_nodes`, `domain`, `tag`, `exclude_tags`.

### `cashew_extract`

Explicitly persist a conversation turn. Accepts `user_content` and `assistant_content`. Bypasses the sync queue — runs synchronously.

## LLM Integration

`llm_aux_role` selects an explicitly configured Hermes auxiliary role. The
default role name is `"memory"`, but the provider never creates or modifies the
mapping. To opt in, configure `auxiliary.memory` in Hermes `config.yaml`:

```yaml
auxiliary:
  memory:
    provider: opencode-go
    model: deepseek-v4-flash
    base_url: https://opencode.ai/zen/go/v1
```

The Hermes-resolved client supplies transport and authentication. Cashew caps
each prompt at 32,000 characters, requests at 1,024 tokens, and waits at most
30 seconds for the caller-facing result. A provider request can finish after
that deadline, so at most four outstanding requests are allowed process-wide;
additional requests fail closed until one finishes. Cashew does not use the
Hermes task retry/fallback ladder for these bounded extraction calls.

This enables:
- **LLM extraction** — Cashew uses the model to extract typed nodes and edges from conversation turns
- **Think cycles** — Periodic cross-domain insight generation (every `think_interval` turns)
- **Sleep cycles** — Graph consolidation (dedup, cross-link, dream, decay, core memory promotion) on the persistent Hermes cron schedule
- **Pre-compress insight extraction** — Before context compression discards old messages, extracts conversation-arc patterns (topic shifts, framing changes, implicit decisions) using a dedicated LLM prompt. Silent-degrades without LLM.

Without LLM, Cashew falls back to heuristic extraction.

## Logs

Plugin logs go to `~/.hermes/logs/agent.log` (not gateway.log — the gateway has a component filter).

Key log lines to watch:
```
INFO plugins.memory.cashew: llm_aux_role='memory': using opencode-go deepseek-v4-flash ...
INFO plugins.memory.cashew: on_session_end called: ...
INFO plugins.memory.cashew: think cycle produced 2 insight(s) on cluster: ...
WARNING plugins.memory.cashew: think cycle failed ...
WARNING plugins.memory.cashew: on_pre_compress failed ...
```
